# 📊 Data Science Mini Projects Portfolio

This repository contains a collection of beginner-friendly Python and Data Science projects.  
The projects focus on **data analysis, machine learning, and numerical computing**, helping build a strong foundation in Data Science.

---

## 📁 Projects Included

### 1. 🧮 Matrix Operations Tool using NumPy

A Python-based tool to perform basic matrix operations using NumPy.

#### 🔹 Features:
- Matrix addition and subtraction
- Matrix multiplication
- Transpose of matrix
- Determinant calculation
- Matrix inverse (if applicable)

#### 🛠️ Technologies:
- Python
- NumPy

---

### 2. 🏠 House Price Prediction using Linear Regression

A machine learning model that predicts house prices based on input features.

#### 🔹 Features:
- Data preprocessing and cleaning
- Feature selection
- Linear Regression model training
- House price prediction
- Model evaluation (MAE, MSE, R² Score)

#### 🛠️ Technologies:
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

### 3. 📚 Student Performance Analysis

A data analysis project to study student performance based on various factors.

#### 🔹 Features:
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Visualization using graphs
- Correlation analysis between variables
- Performance insights

#### 🛠️ Technologies:
- Python
- Pandas
- Matplotlib
- Seaborn
